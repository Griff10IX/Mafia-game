# Travel location images

Place one image per location here. The filename must match the location name, lowercased with spaces as dashes:

- **New York** → `new-york.png` (or `.jpg`)
- **Chicago** → `chicago.png`
- **Los Angeles** → `los-angeles.png`

Only `.png` is requested by the app; you can use `.jpg` if you rename the slug in code or add support for multiple extensions.

Images appear in the "Current Location" box and on each destination card on the Travel page. If a file is missing, the map pin icon is shown instead.
